**1. Теория и база**

- **Прямое условие Фано:**
    
    Ни одно кодовое слово не должно быть началом (префиксом) другого кодового слова.
    
    _Пример:_ если есть код `01`, то кодов `010` или `011` быть не может.
    
- **Обратное условие Фано:**
    
    Ни одно кодовое слово не должно быть концом (суффиксом) другого кодового слова.
    
    _Пример:_ если есть код `10`, то кодов `010` или `110` быть не может.
    

> **Важно для ЕГЭ:** если в условии просто написано «удовлетворяет условию Фано» (без слова «обратное»), всегда используется прямое условие Фано.

___
___**2. Главный инструмент — Двоичное дерево**

Все задачи решаются через построение двоичного дерева:

Plaintext

```
                  (корень)
                 /        \
               0            1
             /   \        /   \
           00     01    10     11
          /  \          / \
        000  001      100 101
```

- **Корень:** стартовая точка (пустая строка).
    
- **Рёбра:** влево — `0`, вправо — `1`.
    
- **Лист (занятый узел):** буква алфавита. Продолжать ветвление вниз из занятого узла **запрещено** (нарушит условие Фано).
    
- **Свободный узел:** доступная позиция для новой буквы или дальнейшего расщепления.
    

___
**3. Алгоритм решения типовой задачи**

1. **Анализ условия:**
    
    - Проверить, сколько всего букв в алфавите (если даны коды для 4 букв, а в алфавите их 6 — нужно оставить ветки под оставшиеся 2).
        
    - Посчитать частоту появления каждой буквы в слове (если требуется найти длину закодированного сообщения).
        
2. **Построение дерева:**
    
    - Отметить на дереве все известные коды и заблокировать их ветви.
        
3. **Поиск свободных веток:**
    
    - Выписать все доступные незанятые узлы подходящей длины.
        
4. **Оптимизация под вопрос:**
    
    - _Минимизация длины сообщения:_ самые частые буквы ставить на самые короткие ветки.
        
    - _Поиск конкретного кода:_ при равной минимальной длине для наименьшего значения брать код с нулями в приоритете (`0... < 1...`), для наибольшего — с единицами.
    
___
**4. Чек-лист частых ошибок**

- Забыли оставить резервные ветки для незадействованных букв алфавита.
    
- Записали в ответ двоичный код вместо его длины (или наоборот).
    
- Продолжили ветвление вниз из узла, где уже зафиксирована буква.
